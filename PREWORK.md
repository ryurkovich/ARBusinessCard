# Prework — do this before the workshop

About **20–30 minutes**. Finish these steps so class time is spent building, not installing.

You need:
- A laptop (Mac or Windows)
- A phone (iPhone/iPad with Safari, or Android with Chrome)
- Wi‑Fi

---

## 1. Create a free GitHub account

1. Open [https://github.com](https://github.com) in your browser.
2. Click **Sign up** and follow the steps (email + password).
3. Verify your email if GitHub asks you to.
4. Sign in once so you know your **username** (it appears in the top-right avatar menu).

## 2. Install Google Antigravity

1. Download the **standard** Antigravity installer (not an “agents-only” build) from the link your instructor shares.
2. Install and open Antigravity once to confirm it launches.

---

## 3. Sign in to GitHub inside Antigravity (no SSH keys)

This is the safe way to connect GitHub. You will use a browser login. **Never paste a password, personal access token, or SSH private key into the AI chat.**

1. Open Antigravity.
2. Open the account / sign-in area (often the account icon in the lower-left, or **Accounts** in the Command Palette).
3. Choose **Sign in with GitHub** (or **Sign in to GitHub**).
4. Your browser opens → approve access for Antigravity → return to the IDE.
5. Confirm your GitHub username appears as signed in.

If anything asks you to “generate an SSH key” or “paste a token into chat,” **stop** and use Sign in with GitHub instead.

---

## 4. Download one 3D model (your personalization)

1. Open [https://poly.pizza/](https://poly.pizza/) in your browser.
2. Search for something fun (animal, robot, food, logo-ish object).
3. Prefer a **small** model (under ~5 MB if the site shows size).
4. Download the **`.glb`** file.
5. Save it somewhere easy to find: **Desktop** or **Downloads**.

You will drag this file into the project during class.
